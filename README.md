# QRLab

Интерактивный макет Avalonia по четырём экранам из приложенного референса.

```powershell
dotnet run --project QRLab.View
```

Проверки:

```powershell
dotnet test QRLab.sln
```

## Что можно попробовать

- **Генерация:** один образец или пакет, QR/штрихкод, шаблон и нумерация, размеры, коррекция, библиотека наборов, форма экспорта, выбор образца в очереди.
- **Мутации:** добавление операций, выбор кадра, настройка параметров, отмена/повтор, сброс, применение цепочки ко всему набору. Клик по изображению добавляет мазок; инструмент «Рука» перемещает изображение, колесо меняет масштаб.
- **Считывание:** параметры прогона, запуск, статистика, поиск, фильтрация успешных/ошибочных образцов, выбор строки, форма экспорта CSV.
- **Сравнение:** переход между образцами, режимы «Рядом», «Наложение» с прозрачностью, «Разница», общий масштаб, возврат к редактированию.

Выбор образца и настройки форм сохраняются при переключении экранов. Начальный набор содержит 120 демонстрационных образцов с готовыми результатами, чтобы все экраны можно было оценить сразу.

## Разделение ответственности

- `QRLab.View/Views` — четыре самостоятельных экрана и главное окно.
- `QRLab.View/ViewModels` — состояние интерфейса, команды и общее рабочее пространство. Code-behind экранов только загружает XAML.
- `QRLab.View/Controls/CodePreview.cs` — отрисовка предоставленной матрицы и обработка жестов просмотра; генерации кода здесь нет.
- `QRLab.Core/Services/IPrototypeData.cs` — контракт данных, настроек, кадров, распознавания и экспорта.
- `QRLab.Image/Demo/PrototypeData.cs` — единственная реализация заглушки. Синтетические матрицы, искажения и результаты распознавания находятся здесь. Экспорт возвращает демонстрационную квитанцию и не создаёт файлов.
- `QRLab.View/App.axaml.cs` — место подключения провайдера. Для подключения настоящего движка следует заменить реализацию `IPrototypeData`.

Синтетические изображения не являются настоящими QR-кодами. Генератор, растровая обработка, файловое хранилище и декодер пока не реализованы.

Для получения снимков четырёх экранов через headless-тест:

```powershell
$env:QRLAB_CAPTURE = "$PWD/artifacts/preview"
dotnet test QRLab.sln --filter AllFourScreensLoadAndNavigationChangesVisibleContent
```
